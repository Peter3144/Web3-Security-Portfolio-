The attacker deposits an amount matching the `MIN_FIRST_DEPOSIT` threshold to satisfy the initialization check, immediately calls `withdraw()` to extract all but one atomic share unit ("dust"), and retains control over an un-anchored pool. Its explicit purpose, per the protocol's architectural documentation, is to guarantee that any outstanding unhealthy debt position remains economically viable for external liquidators to clean up relative to the gas dynamics of the host blockchain network.While Morpho Midnight's core codebase is hyper-optimized and subjected to strict automated formal verification (the contest turned up zero High or Medium severity findings), a critical integration gap was identified. The safety checks ensuring a position cannot fall below `dustThreshold` are isolated exclusively within the liquidation processing loop. The `repay` and `withdrawCollateral` functions contain zero checks regarding the residual state of the position.Consequently, any participant can organically or deliberately bypass the security boundary. A user can establish a standard healthy borrowing position, then execute a sequence of `repay` and `withdrawCollateral` calls designed to downscale their liabilities directly below the `dustThreshold` line.This shifts the debt profile into a structurally unliquidatable state. Because liquidation execution costs outpace the value of the collateral backing it, rational liquidators will refuse to interact with the position. Critically, because bad-debt socialization mechanics are bound tightly to active liquidation triggers, this bad debt sits permanently hidden on-chain — it can never be expunged, permanently inflating the system's `totalUnits` tracking and misrepresenting pool solvency.```solidity// Vulnerable implementation within the core state loop:function repay(...) external {    // Debt reduced with no minimum remainder enforced    position[id][onBehalf].debt -= UtilsLib.toUint128(units);    marketState[id].withdrawable += UtilsLib.toUint128(units);    // ...}```#### Remediation StrategiesThe security invariant must be enforced across all state-altering access routes to prevent position degradation.
